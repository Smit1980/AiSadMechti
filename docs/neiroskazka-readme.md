# НейроСказка AI — отдельная версия «НейроСада»

## Что открывать

- `neiroskazka.html` — новая интерактивная тетрадь.
- `neiroskazka-presentation.html` — та же колода из 12 слайдов в режиме 16:9. Ссылка `#slide-3` откроет третий слайд.
- `docs/neiroskazka-slide-prompts.md` — 12 промптов для иллюстраций и отдельный промпт для обложки. Слайдовые изображения пока не создавались: их подготовит и загрузит владелец.

Открывайте HTML локально в браузере или из корня GitHub Pages. Сборщик, сервер и регистрация не нужны. Для печати используйте браузерное меню печати или `neiroskazka.html?print=1`.

## Состав и редактирование

Новая страница сохраняет действующие разделы рабочей тетради: восемь этапов на 90 минут, библиотеку 50 запросов, конструкторы, семь проверок, шесть полей заметок, каталог ресурсов и учебные примеры без ИИ-сервиса. Слайды 1–12 находятся в `#intro-slides`; их заголовки и тексты редактируются прямо в `neiroskazka.html`. `neiroskazka-presentation.html` показывает эту же колоду, поэтому второй набор слайдов править не нужно. Стили — в `neiroskazka.css`, интерактивы новой колоды — в `neiroskazka.js`, локальная копия логики конструктора — в `neiroskazka-workshop.js`.

Слайдовые иллюстрации позже подключаются как декоративные изображения по именам из `docs/neiroskazka-slide-prompts.md`. Текст, числа, формулы и кнопки должны остаться редактируемыми HTML/SVG. Храните исходники изображений и проверяйте alt и кадрирование на 16:9 и мобильном экране. Главный предоставленный референс сохранён в `assets/neiroskazka/master-reference.png`; оптимизированная обложка — `master-reference.webp` (406 556 байт). QR пользователя сохранён как `assets/neiroskazka/qr-max.png` без изменений; он считывается в `https://max.ru/join/WWR_dfNXSUyW-a0xuiRjyf4OByF07DYHxrFYOJDwZ8M`.

Заметки существуют только во вкладке до обновления страницы. Для сохранения нажмите «Скачать записи .txt». Поля не отправляются на сервер и не сохраняются в `localStorage`.

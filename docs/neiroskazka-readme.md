# НейроСказка AI — отдельная версия «НейроСада»

## Что открывать

- neiroskazka.html — рабочая страница и 16 готовых слайдов.
- neiroskazka-presentation.html — показ 16:9 без остальных разделов страницы. Поддерживает прежние форматы ссылок #slide-N и #intro-N для N от 1 до 16.
- docs/neiroskazka-slide-map.md — порядок 16 слайдов, исходные файлы и методические уточнения.
- docs/neiroskazka-slide-prompts.md — архив промптов для альтернативных иллюстраций.

Сборщик и сервер не нужны: откройте HTML локально или через GitHub Pages. Для печати используйте меню браузера.

## Состав

Основная колода находится в #neiroskazka-slides. Это 16 предоставленных кадров в assets/neiroskazka/slides/, показанных в последовательности занятия: задача → черновик → модель → уточнение → проверка → защита данных. Над кадром находятся настоящие кнопки навигации, выбора слайда, режима чтения и полноэкранного показа.

Интерактивные разборы из предыдущей версии сохранены ниже в #intro-slides: они дополняют показ, а не входят в счётчик основной колоды. Сохранены восемь этапов на 90 минут, библиотека 50 запросов, конструкторы, семь проверок и заметки.

Возраст в слайдах — учебный пример. В реальном запросе всегда указывайте конкретную группу и реальные условия. Схемы токенов и контекста упрощены; память, файлы и поиск зависят от сервиса. Не вводите персональные данные детей и семей.
